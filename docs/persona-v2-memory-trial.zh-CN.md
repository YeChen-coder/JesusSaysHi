# 人设 v2 + "经文当记忆"试跑（2026-10-21）

**怎么跑的**：用 [persona-draft-v2.zh-CN.md](persona-draft-v2.zh-CN.md) 的人设。他手上没有检索工具；从第二轮起，系统每轮在后台检索一次，挑一句经文作为"记忆"给他。链路是真实的：RAGFlow、gpt-realtime-2.1-mini 文字模式。四个场景（面试被拒、学不会、想念家人、和妈妈吵架），每个三轮，各跑 2 遍，共 24 轮。

**"记忆"每轮做的事**（[memory.py](../memory.py)）：

1. 用小模型把最近两句话改写成主题词；
2. RAGFlow 检索（混合检索 + 重排，低于 0.30 就放弃）；
3. 用小模型从检索到的段落里挑**至多一句**（可以只取一节里耶稣说的那部分，代码会校验是不是一字不差的原文片段），挑不出就返回空；
4. 作为一条 `MEMORY` 系统消息加进对话，由他决定说不说。

## 结果

| | 数字 |
|---|---|
| 有资格给记忆的轮次（第 2、3 轮） | 16 |
| 实际给了记忆 | 16（挑选器一次都没选"不给"） |
| 他说了记忆，且一字不差 | **16 / 16** |
| 说成了意译 | 0 |
| 自己凭记忆另引了没给过的经文 | **0**（检查报了 7 处，逐条核对全是误报，见下） |
| 每轮等待时间 | 改写约 0.9 秒 + 检索约 0.6 秒 + 挑选约 1 秒，合计约 2.5 秒 |

**结论：把检索当记忆，"引得准"这件事完全成立**：给了就一字不差地说，不给就不说。问题都出在**挑什么**，以及**怎么说出口**。

## 说出口的样子（中文意译）

- **好的**："我听得出那份羞愧，我的孩子。就像口袋里揣着一块石头，哪怕有人背着你走了很远的路。'相离还远，他父亲看见，就动了慈心。'我想让你这样看待此刻：有一扇门在等你，一个家愿意看见你。"
- **出戏的**："我想起一句话：'你们比许多麻雀还贵重'"（**把"系统给了他一段记忆"说漏了**）
- **经历用得好的**："我小时候坐在教师中间，听、问，一点一点长进。明白常常像面包发起来，不是一下子的。"（学不会）／"我也走过很多天没地方睡的路"（想家）

## 已经改了的（在你看这份文档之前）

1. **去重按"说的话"而不是按出处**：说过"比麻雀还贵重"，就不会再换成平行经文的出处重新给。
2. **挑选器加了规则**：要符合对方在自己故事里的位置（道歉的人不给"你要饶恕别人"）；不挑带叙述的片段；同一个意思不重复给。
3. **记忆提示改了措辞**，不再让他说"我想起一句话"。第一次改完，他又把提示里的"as my own"原样念了出来，已经再改一次。
4. **"自己另引经文"的检查**：如果一句话就是给他的那句记忆，即使它也能匹配平行经文或常见短语，也不再报；整部福音书范围的比对只看 6 个词以上的逐字引用。之前那 7 处误报都属于这几类。

改完后重跑了两个场景：立场反了的问题没再出现，"比麻雀还贵重"只出现了一次。

## 还没解决的

- **等待时间约 2.5 秒**，语音里明显。可以把改写关掉（`JESUS_MEMORY_REWRITE=false`），大约省 1 秒，但检索质量可能下降，需要对比。
- **挑选器从不选"不给"**：16 次全给了。v2 的原意是"有真正贴切的才给"，现在几乎每轮都有经文。是否需要更克制，要你来定。
- **回复长度没守住**：语音实测里出现过一条 30 秒的回复。
- **人设口吻**：仍然偶尔追问太多、给一点实用建议，比 v1 好，但还没完全去掉。

## 日志在哪

- `logs/sessions/<时间>_<会话>.jsonl`：每个会话一份时间线。`memory` 事件里有改写出的主题词、检索到的段落和重排分数、候选句数、挑选器选了什么和理由、各步耗时、总等待时间；`memory_check` 事件记录他有没有说、是否一字不差、有没有另引经文；还有你说的原话、他的回复原文、危机检测结果、打断和播放的细节。
- `logs/retrieval.jsonl`：每次 RAGFlow 检索的原始记录，包括检索词、前 10 个候选、混合分和重排分、是否放弃。
- `logs/jesus.log`：运行日志。每条记忆和每次"另引了经文"都会单独打一行。
